# Установка Plex-Kinopois

Эта инструкция рассчитана на обычную домашнюю установку. Plex Media Server и Plex-Kinopois могут работать на одном компьютере или на разных устройствах в одной сети.

## Что понадобится

- Plex Media Server версии 1.43 или новее;
- Docker Desktop для Windows либо Docker Engine с Compose для Linux;
- бесплатный API-ключ Kinopoisk Unofficial;
- адрес компьютера, на котором будет работать Plex-Kinopois.

Видео и база данных Plex не передаются контейнеру. Сервис получает метаданные из внешних источников и отвечает Plex по HTTP.

## 1. Получите API-ключ КиноПоиска

1. Откройте [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech).
2. Зарегистрируйтесь или войдите.
3. Создайте API-ключ в профиле.
4. Сохраните ключ: он понадобится после первого запуска Plex-Kinopois.

Не добавляйте ключ в файлы Git и не публикуйте его.

## 2. Установите Docker

### Windows 10/11

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Во время установки разрешите использование WSL 2, если установщик предложит.
3. Перезагрузите Windows, запустите Docker Desktop и дождитесь статуса **Engine running**.
4. Откройте PowerShell и проверьте:

```powershell
docker --version
docker compose version
```

### Debian или Ubuntu

```bash
sudo apt update
sudo apt install -y docker.io docker-compose git
sudo systemctl enable --now docker
sudo usermod -aG docker "$USER"
```

После добавления пользователя в группу выйдите из системы и войдите снова. Затем проверьте:

```bash
docker --version
docker compose version
```

На других Linux-дистрибутивах установите Docker Engine и Compose из репозитория вашего дистрибутива или по официальной инструкции Docker.

## 3. Скачайте проект

### Windows PowerShell

```powershell
cd $HOME
git clone https://github.com/NebulaDark/Plex-Kinopois.git
cd Plex-Kinopois
Copy-Item .env.example .env
```

Если Git не установлен, скачайте ZIP на странице GitHub, распакуйте его и откройте PowerShell в папке проекта.

### Linux

```bash
git clone https://github.com/NebulaDark/Plex-Kinopois.git
cd Plex-Kinopois
cp .env.example .env
```

## 4. Настройте сетевой доступ

Откройте файл `.env` в текстовом редакторе.

Если Plex работает на другом компьютере, установите:

```dotenv
BIND_ADDRESS=0.0.0.0
PORT=8765
```

Если Plex и Plex-Kinopois работают на одном компьютере, можно оставить:

```dotenv
BIND_ADDRESS=127.0.0.1
PORT=8765
```

При использовании Windows Firewall разрешите входящие TCP-подключения к порту 8765 только из домашней сети и с компьютера Plex. Не публикуйте этот порт напрямую в интернет.

## 5. Запустите сервис

В папке проекта выполните:

```bash
docker compose up -d --build
```

Проверьте состояние:

```bash
docker compose ps
```

У контейнера через некоторое время должен появиться статус `healthy`.

Получите ключ входа администратора:

```bash
docker compose exec kinopois cat /data/admin-token
```

Это ключ входа в настройки Plex-Kinopois. Он не является API-ключом КиноПоиска. Не публикуйте и не отправляйте его другим людям.

## 6. Откройте настройки Plex-Kinopois

В браузере откройте:

- `http://127.0.0.1:8765`, если сервис работает на этом же компьютере;
- `http://IP-КОМПЬЮТЕРА:8765`, если сервис работает на другом устройстве.

Введите ключ администратора из предыдущего шага.

Откройте раздел **Источники**, вставьте ключ **Kinopoisk Unofficial** и нажмите **Проверить**. После успешной проверки сохранённый источник будет отмечен золотистой рамкой.

Ключи TMDb, Fanart.tv и OMDb необязательны. Они добавляют изображения, коллекции и дополнительные рейтинги.

## 7. Добавьте провайдеры в Plex

Откройте Plex Web и перейдите:

**Настройки → ваш Plex Media Server → Metadata Agents**

Нажмите **Add Provider** и добавьте два адреса по отдельности:

```text
http://IP-PLEX-KINOPOIS:8765/providers/movies
http://IP-PLEX-KINOPOIS:8765/providers/shows
```

Если Plex-Kinopois и Plex установлены на одном Windows-компьютере, вместо IP можно использовать `127.0.0.1`. Если Plex работает в контейнере, `127.0.0.1` указывает на сам контейнер Plex; используйте IP хоста или доступное контейнеру DNS-имя.

После добавления должны появиться поставщики **Kinopoisk Movies** и **Kinopoisk Shows**.

## 8. Создайте Metadata Agents

На странице **Metadata Agents** нажмите **Add Agent**.

Для фильмов:

1. Название: например, `Kinopoisk Movies`.
2. Primary metadata provider: **Plex Movie** для стандартного распознавания Plex либо **Kinopoisk Movies** для распознавания через КиноПоиск.
3. Добавьте **Kinopoisk Movies** в дополнительные источники, если основным выбран Plex Movie.
4. Поднимите Kinopoisk Movies выше других дополнительных источников.
5. Сохраните агент.

Для сериалов повторите те же действия с **Plex Series** и **Kinopoisk Shows**.

## 9. Подключите агент к библиотеке

Сначала создайте небольшую тестовую библиотеку.

1. В Plex откройте меню библиотеки и выберите **Управление библиотекой → Редактировать**.
2. Откройте **Дополнительные настройки**.
3. Для библиотеки фильмов выберите созданный агент Kinopoisk Movies.
4. Для библиотеки сериалов выберите созданный агент Kinopoisk Shows.
5. Сохраните изменения.
6. Запустите **Сканировать файлы библиотеки**, затем **Обновить все метаданные**.

Для отдельной неверно найденной карточки используйте **⋯ → Исправить совпадение**. В Plex-Kinopois также поддерживается поиск по `kp-ID`, ссылке КиноПоиска и IMDb ID.

## 10. Проверка работы

Проверьте:

- русское и английское название;
- описание, год и рейтинг;
- постер и фон;
- актёров и съёмочную группу;
- сезоны и эпизоды сериалов.

В интерфейсе Plex-Kinopois раздел **Журнал** показывает последние безопасно сохранённые запросы. Query-параметры, тела запросов, заголовки, cookie и API-ключи туда не записываются.

Локальная проверка сервиса:

```bash
curl http://127.0.0.1:8765/health
```

Ожидаемый ответ содержит `"ok": true`.

## Обновление

В папке проекта выполните:

```bash
git pull --ff-only
docker compose up -d --build
```

Настройки и ключи сохраняются в Docker volume и не удаляются при обычном обновлении контейнера.

## Остановка и запуск

```bash
docker compose stop
docker compose start
```

Чтобы удалить контейнер, сохранив настройки:

```bash
docker compose down
```

Не добавляйте флаг `-v`, если хотите сохранить ключи, настройки, кэш и ручные сопоставления.

## Резервная копия

Узнайте имя volume:

```bash
docker volume ls
```

По умолчанию данные находятся в volume `plex-kinopois_kinopois-data`. Перед резервным копированием остановите контейнер. Не публикуйте резервную копию: она содержит ключ администратора и API-ключи.

## HTTPS

Встроенный HTTPS описан в [README.md](README.md#https). Для домашней сети проще оставить сервис доступным только внутри сети. Для удалённого доступа рекомендуется Caddy или Nginx с сертификатом Let's Encrypt, закрытым обычным HTTP-портом и ограничением доступа по IP или VPN.

После включения HTTPS замените `http://` на `https://` в адресах обоих провайдеров Plex.

## Частые проблемы

### Страница не открывается

Проверьте `docker compose ps`, значение `BIND_ADDRESS`, IP компьютера и правило Windows Firewall. Посмотрите журнал контейнера:

```bash
docker compose logs --tail 100 kinopois
```

### Plex не принимает адрес провайдера

Откройте адрес `/providers/movies` с компьютера Plex. Должен вернуться XML или JSON-манифест. Проверьте, что Plex обращается к правильному IP, а firewall разрешает соединение.

### Метаданные не обновились

Убедитесь, что библиотека использует созданный Metadata Agent, а не встроенный Plex Movie/Plex Series. Затем запустите **Обновить все метаданные**. Для одной карточки используйте **Исправить совпадение**.

### Ключ КиноПоиска не проходит проверку

Проверьте ключ на странице источников, лимиты аккаунта Kinopoisk Unofficial, системное время компьютера и доступ контейнера в интернет.

### Как полностью начать заново

Сначала сохраните нужные данные. Полное удаление volume необратимо:

```bash
docker compose down -v
```

После следующего запуска будет создан новый ключ администратора и пустая база настроек.
