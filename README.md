# Plex-Kinopois

Современный HTTP Metadata Provider для Plex Media Server 1.43+. Предоставляет отдельные источники для фильмов и сериалов, используя Kinopoisk Unofficial API и необязательные дополнительные источники.

## Возможности

- фильмы, сериалы, сезоны и эпизоды;
- поиск по названию и году, `kp-123`, ссылке КиноПоиска и IMDb ID;
- русские названия и описания, постеры, фоны, жанры, страны, актёры и съёмочная группа;
- рейтинги КиноПоиска и IMDb; TMDb и Rotten Tomatoes при наличии дополнительных ключей;
- коллекции и дополнительные изображения через TMDb/Fanart.tv;
- защищённая страница настроек на русском и английском;
- кэш, ограничение частоты запросов, ручные сопоставления и диагностика;
- Docker-образ без прав root, с read-only файловой системой.

Рецензии и видеоматериалы доступны в странице предпросмотра. На недокументированный запрос Plex `/extras` сервис возвращает корректный пустой контейнер. Нативное отображение и воспроизведение удалённых extras в Plex не считается поддержанным, пока Plex не опубликует стабильную схему и она не будет подтверждена интеграционным тестом.

## Запуск

```bash
cp .env.example .env
# Для доступа с другого компьютера укажите в .env BIND_ADDRESS=0.0.0.0
docker compose up -d --build
docker compose exec kinopois cat /data/admin-token
```

Откройте `http://IP-СЕРВЕРА:8765`, войдите с выведенным ключом администратора и сохраните API-ключ КиноПоиска.

URL поставщиков:

- `http://IP-СЕРВЕРА:8765/providers/movies`
- `http://IP-СЕРВЕРА:8765/providers/shows`

Добавьте их в `Settings → Metadata Agents`. Рекомендуемая схема: Plex Movie/Plex Series остаются основными для сопоставления, а соответствующий Kinopoisk provider располагается выше по приоритету метаданных. Для самостоятельного сопоставления КиноПоиском выберите его основным поставщиком.

Сначала используйте отдельные тестовые библиотеки. Переход основной библиотеки и обновление всех метаданных могут массово изменить карточки.

## Проверка

```bash
python -m unittest discover -v
docker compose config
docker compose build
```

## Данные и резервное копирование

Настройки, ключ администратора, сопоставления и кэш находятся в Docker volume `plex-kinopois_kinopois-data`. API-ключи не возвращаются браузеру после сохранения и не выводятся в журналы.

## Независимый проект

Проект не связан с Plex Inc., Яндексом или КиноПоиском. Используйте API и изображения в соответствии с условиями выбранных источников.
