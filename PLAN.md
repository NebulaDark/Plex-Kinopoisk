# Plex-Kinopois — план разработки

Цель: заменить Kinopoisk.bundle современными HTTP Metadata Providers для Plex 1.43+, с фильмами, сериалами, Docker и настройками RU/EN.

## Этапы

- [x] Проверить VM и документацию протокола Plex и Kinopoisk Unofficial API.
- [x] Создать независимый сервис, постоянные настройки, кэш и защищённое управление.
- [x] Реализовать поиск по названию/году, IMDb и kp-ID; ручные сопоставления.
- [x] Реализовать фильмы, сериалы, сезоны, эпизоды и постраничные ответы Plex.
- [x] Перенести доступные поля и настройки старого bundle; дополнительные источники подключать только с пользовательскими ключами.
- [x] Создать страницу настроек RU/EN, диагностику источников и предпросмотр карточек.
- [x] Подготовить Docker Compose и инструкции Debian/Windows, запуск и резервирование.
- [x] Проверить контракт, ошибки API, защиту настроек и сериализацию автоматическими тестами.
- [x] Собрать и запустить контейнер на Debian VM; проверить HTTP-манифесты и страницу настроек.
- [x] Визуально проверить интерфейс в обычном браузере по снимку пользователя.
- [x] После ввода пользовательского API-ключа проверить живые фильмы/сериалы, сезоны, эпизоды, изображения, рейтинги, рецензии и видеоссылки.
- [x] На тестовых библиотеках Plex пользователя проверить matching, обновление карточек, картинки и совместимый ответ extras.

## Решения

- Разработка: /home/mgm/Projects/Plex-Kinopois на codex.21port.ru.
- Plex остаётся на Windows 10, версия 1.43.3.10896.
- Два провайдера: /providers/movies и /providers/shows.
- Основной рекомендованный режим: распознавание Plex, данные КиноПоиска выше по приоритету; самостоятельное распознавание также поддерживается.
- Без монтирования видео и без прямого изменения базы Plex.
- Ключи хранятся только в data/, не возвращаются интерфейсом и не входят в Git.
- Нельзя считать старые Freebase/IVA/iTunes-интеграции работоспособными без актуального подтверждения. Неподдержанные функции отмечаются явно.

## Критерий готовности

Автотесты и контейнер проходят проверки; пользователь может ввести ключ локально, добавить URL провайдеров и проверить фильмы и сериалы. Полная совместимость с пользовательским Plex считается проверенной только после тестовой библиотеки.
