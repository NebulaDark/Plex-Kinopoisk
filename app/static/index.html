PLEX 1.43+

Подключение Plex

  1. Добавьте поставщиков

    В настройках Plex откройте Metadata Agents и добавьте каждый адрес как отдельного поставщика.

    Фильмы
    Сериалы

    Адрес должен быть доступен с компьютера Plex. Если страница открыта через SSH-туннель, замените localhost на адрес VM.

  2. Создайте два агента

    Для фильмов выберите Plex Movie основным, добавьте Kinopoisk Movies и поднимите его выше по приоритету данных. Для сериалов повторите с Plex Series и Kinopoisk Shows. При необходимости распознавания самим КиноПоиском выберите его основным.

  3. Проверьте тестовую библиотеку

    Назначьте новых агентов отдельным тестовым библиотекам. Проверьте названия, постеры, сезоны и эпизоды перед переносом основной коллекции.
